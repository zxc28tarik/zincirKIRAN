# Research

Bu klasör production kodundan ayrılmış araştırma kayıtlarını tutar.

Planlanan alt alanlar:

- `preregistrations/` — testten önce yazılan hipotez/protokol/başarı kriterleri

- `experiments/` — deney tanımları ve immutable sonuç referansları
